// ! Type conversion 
// type conversion is the process of converting a value from one data type to another data type 
// Types of type conversion 
// !1 . implicit (type coercion)
// implicit type conversion is also called as type coercion it is implicitly done by the js engine 
// it happens in the case of operators like + , - , * , &&  , == , !=
// ex -> '5'+2 -> 2 is converted to string first and than concatenated 
// -> '5'-2 -> 5 is converted to number 
// ! Explicit Type conversion 
// We can perform explicit type conversion by using some functions 
// ! Number('10') --> 10
// ! Number('10Kg') --> NaN
// ! String(20) --> '20'
// ! Boolean(1) --> true
